# Chat Bubbles (Fabric, Minecraft 26.2)

Клиентский мод: сообщения чата появляются облачками в мире вокруг персонажа.

- Прицелься в облачко (оно подсветится жёлтым) и кликни ЛКМ, чтобы убрать его.
- Облачко исчезает само через заданное время (по умолчанию 10 с).
- `O` открывает меню настроек.

Сборка: любой push запускает GitHub Actions, готовый jar лежит в артефакте `chatbubbles-jar`.
Нужны Fabric Loader 0.19.3+, Fabric API для 26.2 и Java 25.
